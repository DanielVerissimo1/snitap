**Snitap** é uma landing page animada de patins, desenvolvida como um dos desafios da formação da **Rocketseat** a partir de um modelo do Figma, com foco em layout responsivo e animações CSS.

## 🚀 Funcionalidades

| Funcionalidade | Descrição |
|----------------|-----------|
| 🎨 **Layout responsivo** | Adaptado para diferentes tamanhos de tela |
| ✨ **Animações CSS** | Efeitos visuais que tornam a experiência mais encantadora |
| 🛼 **Landing Page** | Página de apresentação do produto com design moderno |

## 📚 Conceitos Aplicados

- HTML semântico
- CSS responsivo com media queries
- Animações com `@keyframes` e `transition`
- Fidelidade ao design via Figma

## ▶️ Como Rodar o Projeto

```bash
# Clone o repositório
git clone https://github.com/DanielVerissimo1/snitap

# Acesse a pasta do projeto
cd snitap

# Abra o arquivo index.html no navegador
```
